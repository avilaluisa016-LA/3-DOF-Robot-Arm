# 3-DOF-Robot-Arm

In this project, I developed a small embedded control system for robotic motion using an Adafruit Feather M0 and an 8-Channel PWM Servo Driver. Three servos (SG90 and DS-S006L) are controlled based on input from a KY-023 joystick.

Servo positions are calculated using inverse kinematics, enabling smooth and coordinated movement rather than direct joint control. This approach mirrors techniques used in robotic arms and legged systems.

The goal of the project is to strengthen skills in embedded C/C++, real-time control, and robotics-oriented firmware development.

## What I Learned
- Servo control using external PWM drivers
- Analog input handling from a joystick
- Applying inverse kinematics in embedded systems
- Coordinating multiple actuators in real time
- Integrating hardware and firmware for robotics applications
